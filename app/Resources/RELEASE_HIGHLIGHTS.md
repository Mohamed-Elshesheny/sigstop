**The app now opens on machines that are not mine.**

Every build before this one resolved its message corpus through the build directory of the
computer that compiled it, so it died before showing anything: no window, no Dock icon,
nothing in the menu bar, and no error to report. If you downloaded sigstop and it appeared
to do nothing at all, that was this, and it is fixed.

The menu bar icon also stops claiming a position ahead of icons you arranged yourself. It
now appears where new items go, and you can drag it anywhere with Command held.
